# Shelly Router Watchdog

Надежный watchdog для роутера на базе Shelly Script.

Проект предназначен для автономного контроля домашнего интернет-соединения и автоматического восстановления работы роутера при пропадании доступа в Интернет.

Основная цель проекта — максимальная надежность при долговременной непрерывной работе.


# Router Watchdog для Shelly

# Devices

* Shelly PlusPlugS
* Shelly PlugS Gen3

# Shelly Scripts Overview

Shelly devices run JavaScript directly on-device for local automation and integrations—no cloud or external servers required. Scripts execute on a modified version of Espruino, providing a JavaScript environment that's close to the standard while optimized for embedded systems. 

https://shelly-api-docs.shelly.cloud/gen2/Scripts/Overview

# Основные возможности

- контроль состояния силового реле Shelly;
- автоматическое включение реле при случайном выключении;
- проверка доступности Интернета через несколько независимых URL;
- повторные проверки Интернета перед принятием решения о перезагрузке;
- автоматическая перезагрузка питания роутера;
- ожидание полной загрузки роутера после подачи питания;
- диагностика текущего состояния через объект `info`.

# Принципы проекта

Во время разработки были приняты следующие правила.

## Простая архитектура

Используется один конечный автомат.

Используется один объект состояния (`state`).

Используется один программный таймер.

В проекте отсутствуют вложенные автоматы.

---

## Минимальная связанность

Автомат ничего не знает о типах проверок Интернета.

Проверка Интернета выполняется перебором массива URL.

Добавление нового URL не требует изменения логики автомата.

---

## Надежность

Любая операция восстановления должна приводить систему в гарантированно рабочее состояние.

Например:

если питание уже выключено, вместо попытки выполнить Power Cycle производится обычное включение питания.

---

## Минимальное использование памяти

Проект ориентирован на долговременную работу.

Поэтому:

- используется `Date.now()` вместо `new Date()`;
- отсутствуют анонимные функции;
- отсутствуют замыкания;
- отсутствуют временные объекты без необходимости.

---

## Самодокументируемый код

Каждая функция выполняет только одну задачу.

Названия функций описывают действие.

Все строковые литералы вынесены в константы.

# Проверка Интернета

Интернет считается доступным, если успешно отвечает любой URL из массива:

```javascript
const INTERNET_URLS = [

    "...",

    "...",

    "..."

];
```

Все URL проверяются последовательно.

Первая успешная проверка завершает цикл.

Если все URL недоступны — считается, что Интернет отсутствует.

---

# Повторные проверки

Перед перезагрузкой роутера выполняется несколько полных циклов проверки Интернета.

Каждый цикл включает проверку всех URL.

Только после нескольких полностью неудачных циклов производится перезагрузка питания.

Это уменьшает вероятность ложных перезагрузок.

---

# Power Cycle

Перед выключением питания дополнительно проверяется состояние реле.

Возможны два сценария.

## Реле включено

Выполняется обычный цикл:

```
OFF

↓

ON

↓

ожидание загрузки
```

## Реле уже выключено

Выполняется только включение питания.

Это защищает проект от изменения поведения функции `toggle_after` в будущих версиях прошивки.

---

# Диагностика

Во время работы проект поддерживает объект `info`.

Он содержит сведения о текущем состоянии системы.

Логи Shelly имеют ограниченный объем.

Поэтому основная информация хранится непосредственно в памяти скрипта.

---

# Надежность

Во время разработки проект тестировался следующими сценариями:

- запуск при включенном реле;
- запуск при выключенном реле;
- случайное выключение реле пользователем;
- недоступность одного URL;
- недоступность нескольких URL;
- отсутствие Интернета;
- восстановление Интернета;
- перезагрузка роутера;
- проверка после загрузки роутера.
